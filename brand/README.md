# TicketNest brand files

All logos in one place. The website uses its own copies in `web/public/`; changing files here does not change the live site.

| Folder | What's inside | Use it for |
|---|---|---|
| `current/` | The current app icon (1024, 512, 192, iPhone 180, Android "maskable"), `favicon.svg`, the link-preview image `og-image.png` and a wide banner | Home-screen app, social posts, the main Telegram bot photo |
| `admin/` | Admin logo (T + shield), 1024 / 512, a round Telegram preview and a wide banner | Photo for the **admin alert group** in Telegram, admin documents |
| `payments/` | Payments logo (T + coin), 1024 / 512, a round Telegram preview and a wide banner | Photo for the **payment group** in Telegram |
| `previous/` | The first versions: flat dark app icon and the original favicon | Reference only |

Colours: dark background `#0A0910`, violet `#7C5CFF`, purple `#C45BFF`, pink `#FF6EC7`, cyan `#7AE6FF`.
The `*-telegram-preview.png` files show how each logo looks after Telegram crops it into a circle.

To set a Telegram group photo: open the group → tap its name → Edit → Set new photo → choose the `-1024.png` file.
